# Atta 术语表（大白话版）

> 这份表解释 Atta 架构图里出现的每一个词。每条都有一句话解释和一个生活里的比方。
> 技术细节看不懂没关系，先看比方——比方看懂了，这个词就懂了。

## 怎么读这份表

- **加粗的词**是术语，后面紧跟一句话解释。
- 「比方：」后面是生活里的类比，可以只看这部分。
- 术语按主题分组，不必从头读到尾；最后一节是速查表。

---

## 一、先认识 Atta 本身

**Atta** — 一个"你用文字描述零件，电脑帮你造出来"的工具。比方：你说"我要一个高 95 毫米、带把手的杯子"，它算出形状、量出尺寸、检查做对没有，最后才给你能打印的文件。

**参数化** — 用几个数字描述形状，改数字形状就跟着变。比方：不是画死一张桌子图，而是记下"长 120、宽 60、高 75"，改高度桌子就长高了。

**参数** — 上面那些可以调的数字。

**CAD** — 计算机辅助设计，就是用电脑画工程图、建三维模型。

**内核 / 引擎** — 真正干活的那部分程序，不含界面。比方：汽车的发动机，看不见，但车靠它跑。

**LLM / 语言模型** — 就是 ChatGPT 这类 AI。

**agent（智能体）** — 让 AI 自己一步步动手干活，而不是只跟你聊天。

**LLM-native（为语言模型而生）** — 整个工具是照着"AI 擅长什么、不擅长什么"设计的。AI 擅长读文字和数字、照着错误提示改参数；不擅长盯着图片猜尺寸。所以 Atta 只给 AI 文字和数字。

## 二、六个最核心的词

**spec（规格书）** — 一份文字说明，写清"这个零件长什么样"，而不是存一个已经做好的模型。比方：给厨师的菜谱，而不是一盘做好的菜。有菜谱就能重做，还能改咸淡。

**model_id** — 每造一个模型就发一个编号，像取件单号。比方：干洗店给你一张小票，之后凭小票取衣服，不用再描述那件衣服。

**describe（描述 / 测量）** — 命令 Atta 把模型的真实数字报出来：多长多宽多高、体积多少、有没有破洞、壁有多厚。比方：拿卡尺和电子秤量一遍，然后报数。

**verify（验收）** — 检查这个模型够不够格交付，给一个明确结论。比方：出厂前的质检员盖章。

**deliver（交付）** — 真正导出成文件给你。比方：质检合格了才发货。

**recipe（配方）** — 预先做好的一类常用零件模板，比如杯子、碗、花瓶、齿轮、支架。比方：现成的家具系列，选一个再挑尺寸。

## 三、形状与几何

**几何** — 形状本身。

**mesh（网格）** — 用无数个小三角面拼出来的表面，像马赛克或折纸。电脑最擅长处理这种形状。

**B-rep（边界表示）** — 另一种描述形状的方法：用数学公式精确记录"这里是一个半径 4 毫米的圆柱面"。比方：mesh 像用马赛克拼一个圆，B-rep 像直接写"圆心在这、半径 4"。

**拓扑** — 不管怎么拉伸扭转都不变的性质，主要是"有几个洞、是不是一整块、有没有破口"。比方：甜甜圈和咖啡杯在拓扑上是同一种东西，都只有一个洞。

**genus（亏格）** — 就是洞的个数。甜甜圈是 1，8 字形的椒盐卷饼是 2，实心球是 0。

**manifold（封闭 / 流形）** — 表面严丝合缝，没有破洞、没有多余的边。可以想象成能装水不漏。3D 打印必须是这样。

**winding（绕向）** — 每个三角面的"正面"朝里还是朝外。全朝外才对；有朝里的，电脑会以为里面是外面。

**degenerate faces（退化面）** — 面积为零的三角面，像一根线或一个点，属于废料，会让后续计算出错。

**bbox（包围盒）** — 能把零件整个装进去的最小长方体，报三个数：长、宽、高。比方：寄快递时量箱子的外尺寸。

**壁厚** — 壳体零件的壁有多厚。太薄打印会破。

**曲率** — 表面弯曲的剧烈程度。比方：平桌面曲率是 0，篮球曲率处处一样，刀刃很弯。

**二面角** — 两个相邻面之间的夹角。夹角很尖的地方容易出问题。

**体积** — 占多少立方毫米。

**凸性** — 形状往外鼓的程度。球最凸，带凹槽的不凸。

**对称** — 左右或旋转后能不能重合。

**布尔运算** — 把两个形状做加法（合并）、减法（挖洞）、交集（只留重叠部分）。比方：一块橡皮泥，粘上另一块是合并，用模具压掉一块是挖洞。

**倒角 / 圆角** — 把尖锐的边磨圆或削平。比方：桌角磨圆，不容易磕伤。

**回转** — 把一条二维轮廓绕轴转一圈，得到立体。比方：陶艺拉坯，一条侧影转一圈就是花瓶。

**放样** — 把几个不同大小的圈串起来蒙上布，像把几个呼啦圈用布包成一个筒。

**扫掠** — 拿一个截面沿一条路径推着走，像挤牙膏。

**拉伸** — 把一个二维形状垂直拉出厚度，像压饼干模具再往上提。

**TPMS / gyroid（螺旋曲面）** — 一种像海绵、到处都是通道的复杂曲面，用来做又轻又结实的填充结构。

**SDF（有符号距离场）** — 一种用"离表面多远"来描述形状的数学方法，适合做特别复杂的曲面。

**文字雕刻 / 浮雕** — 在表面上刻凹字或凸字，像刻铭牌。

## 四、测量与验收

**metrology（计量）** — 专门"量尺寸"的那套算法。

**facts（事实卡）** — 一次测量结果的汇总，一行字说清尺寸、体积、有没有洞。

**perceive（感知 / 取景器）** — 不开渲染，直接用文字和字符画给你看形状大概什么样。比方：不用拍照，用字符画勾个轮廓，0.1 秒就出来。

**ASCII 截面** — 用 `#` 和 `.` 这类字符画出的横截面图，像用字符拼的简笔画。

**渲染** — 把三维模型算成一张逼真的图片。慢，但好看。

**三态闸门** — 验收只有三个结论，没有模糊地带：

- **pass（合格）** — 全部检查通过，可以交付。
- **degraded（勉强合格）** — 没有硬伤，但有些小毛病。默认不许交付，要人明确点头才行。
- **fail（不合格）** — 有硬伤，不许交付。

**回执（receipt）** — 验收后留下的一份记录，写明查了哪些项、每项结果、用的什么方法。比方：质检报告单，可以存档、可以复查。

**score（分数）** — 0 到 1 的总体评分。

**warn / error（警告 / 错误）** — 检查项的两个严重级别。error 直接判不合格；warn 只降级成"勉强"。

**skipped（跳过）** — 这个检查项没做。便宜档位会跳过昂贵的检查，但会明确标出来，不会假装查过了。

**exact: false（非精确）** — 这个数字是抽样估算的，不是精确算出来的。Atta 会老实标出来，不装作精确。

**假设台账** — 记录哪些值是"我替你猜的默认值"，哪些是"真量出来的"。比方：菜谱写"盐适量"，那是我替你定的，不是量过的。

**间隙** — 两个零件之间留的空隙。太紧装不进，太松会晃。

**干涉** — 两个零件占到了同一块空间，物理上不可能，等于撞在一起了。

**公差 / 容差** — 允许的误差范围。比方：说"长 100 毫米"，实际 99.8 到 100.2 都算合格。

**AABB（轴对齐包围盒）** — 用方方正正的盒子粗略包住零件，先快速筛掉明显不可能相撞的，省时间。

**包络** — 整个装配体占的总外轮廓尺寸。

**自由度（DOF）** — 一个零件还能自由活动的方向数。完全固定是 0；能上下滑是 1；能转是 1。

**雅可比秩** — 一种数学工具，用来数"到底有几条独立的约束"，从而算出还剩几个自由度。比方：数一数有几根绳子拴住了木偶，就知道它还能怎么动。

**SE(3)** — 三维空间里"平移 + 旋转"的数学说法。装配求解就是在 SE(3) 里找每个零件该摆在哪。

**配合 / 装配约束（mate）** — 规定两个零件怎么对齐，比如"这两个面贴在一起""这两根轴同心"。

**mates（配合清单）** — 一个装配体里所有配合的列表。

**collisions（碰撞）** — 验收时查出来的"零件互相占空间"的情况。

**rank（秩）** — 雅可比矩阵里"独立约束的条数"。自由度就是拿 6 乘以活动零件数，再减掉这个秩。

**端口（port）** — 零件上预留的接口位置，像插座，方便对接。

**包络（envelope）** — 整个装配体占的总外轮廓尺寸。

**tolerance（公差）** — 允许的误差范围。

**IoU（交并比）** — 两个轮廓重叠部分占合并部分的比例，用来判断"像不像"。1 是完全一样，0 是毫无重叠。

**hash（哈希 / 指纹）** — 一串根据内容算出来的字符，内容一样指纹就一样。用来判断"是不是同一个东西"。

**content-addressed（内容寻址）** — 按内容指纹给文件命名，同样的东西永远只存一份。

## 五、三种描述方式

**recipe 模型** — 用现成配方加几个参数。最快。

**graph 模型（特征图）** — 用一堆"积木块"按顺序搭起来。比方：先一块板，再挖两个孔，再把边磨圆。

**feature op（特征操作）** — 一块积木，比如"方块""圆柱""挖洞""镜像""阵列"。

**DAG（有向无环图）** — 有先后顺序、不会绕回自己的流程图。比方：做菜的步骤，不能"先炒后切"又"先切后炒"。

**assembly（装配体）** — 好几个零件组装在一起的整体。

**preset（预设）** — 一组调好的参数，选一个省事。

**constraints（约束）** — 对结果的硬性要求，比如"高度必须在 80 到 120 毫米之间""壁厚至少 2.4 毫米"。

**quality / draft（质量档位 / 草稿）** — 先出粗糙快速的版本看形状，满意了再做精细的。比方：先用铅笔打草稿，再上色。

**patches（补丁 / 增量修改）** — 只发"把高度从 95 改成 100"，不重发整份规格书。

**variant（变体 / 求解）** — 让它自动试很多组参数，找出满足你要求的那一组。

**LHS（拉丁超立方抽样）** — 一种撒点方法，让试样均匀铺满整个范围，不扎堆。

**Nelder-Mead** — 一种"试错找最好"的算法：先试几个点，往好的方向挪，越挪越接近最优。

**Pareto（帕累托前沿）** — 当几个目标互相冲突（比如又轻又结实），不存在一个全面最好的方案，只有一排"各有取舍"的候选。这一排就叫帕累托前沿。

**infeasible（无解）** — 你要的条件互相矛盾，怎么调都做不到。Atta 会老实说"无解"，绝不硬凑一个假答案。

## 六、十个工具

Atta 一共只有十个"命令"，每个都是一个动词。名字前面加 `atta_` 就是给 AI 用的工具名。

| 工具 | 一句话 | 比方 |
|---|---|---|
| **doctor（体检）** | 先检查环境：依赖装好没有、Blender 找得到吗、引擎健康吗 | 开工前检查工具齐不齐 |
| **catalog（目录）** | 列出有哪些配方、哪些积木块、什么参数，附说明书 | 翻菜单 |
| **spec（规格书）** | 校验一份规格书写得对不对；缺的默认值替你补上并记账 | 检查菜谱有没有漏写 |
| **model（建模）** | 真正造出模型，返回一个 `model_id` | 下厨做菜 |
| **variant（变体）** | 自动试很多组参数，找出满足要求的；或采样看有哪些可能 | 试吃调咸淡 |
| **describe（描述）** | 量出真实数字、做字符画、比对两个形状 | 拿卡尺量 |
| **verify（验收）** | 三态判决加回执 | 质检盖章 |
| **preview（预览）** | 渲染成图片，附带图像分析（需要 Blender） | 拍照看效果 |
| **deliver（交付）** | 验收通过后导出文件，附清单 | 合格才发货 |
| **run（流水线）** | 一次调用跑完多步，自动把 `model_id` 传给下一步 | 一条龙服务 |

**doctor / catalog / spec / model / variant / describe / verify / preview / deliver / run** — 就是上面这十个。

**engine（引擎编排）** — 这十个命令背后真正干活的代码，负责把各层串起来。

**probe（探针）** — `describe` 的一个参数，用来问具体的空间问题，比如"这两个零件之间有多少空隙""这个点在不在里面"。

**perception（感知层）** — 不开渲染、只用字符画和数字让你看形状的那套代码。

**solve（求解）** — 自动找参数的那套算法。

**vision（图像分析）** — 分析渲染图片的亮度、色彩、对比度，只给提示，不给合格判决。

## 八、验收检查项

`verify` 会逐项检查，每项都有名字。分成"硬伤"和"小毛病"两类。

**硬伤（error 级，不合格）**

| 检查项 | 查什么 | 比方 |
|---|---|---|
| **closed** | 表面是不是完全封闭、没有破口 | 气球漏不漏气 |
| **manifold** | 有没有多余的边或点，是否规整 | 布料有没有多余的线头 |
| **winding** | 每个面的正反朝向对不对 | 衣服有没有穿反 |
| **volume** | 体积是不是正的、不是零 | 有没有变成一张纸 |
| **components** | 是不是一整块，而不是散成几块 | 别把零件做成了碎片 |
| **degenerate_faces** | 有没有面积为零的废面 | 有没有零宽度的裂缝 |
| **genus** | 洞的个数对不对 | 该一个洞就一个洞 |

**小毛病（warn 级，降级为"勉强"）**

| 检查项 | 查什么 | 比方 |
|---|---|---|
| **min_wall_mm** | 最薄的地方有多厚 | 蛋壳别太薄 |
| **dihedral_max_deg** | 最尖的夹角是多少度 | 别做出刀锋 |
| **curvature_p95_deg** | 弯曲最剧烈的 5% 有多弯 | 别出现意外的尖刺 |
| **bbox.x/y/z** | 长宽高在不在要求范围内 | 别超出柜子尺寸 |
| **volume_mm3** | 体积在不在要求范围内 | 别太重或太轻 |
| **clearance** | 两个零件之间留的空够不够 | 抽屉别卡死 |
| **interference** | 两个零件有没有撞在一起 | 别互相插进去 |
| **holes** | 该有的孔有没有、位置对不对 | 螺丝孔别打歪 |
| **render.\*** | 渲染回执里的检查（分辨率、覆盖率、空帧等） | 照片别拍糊了 |

**三个等级**

- **basic（基础档）** — 只做便宜的检查，跳过壁厚、间隙、孔检测、渲染。跳过的项会明确标 `skipped`，不会假装查过。
- **standard（标准档）** — 默认档位。全部检查都做，质量类问题算 warn。
- **strict（严格档）** — 把壁厚、二面角、曲率、退化面、多体全部升级成 error。只贵约 2%，但"声称能制造"时该用它。

## 九、回执里都有什么

验收完留下的一张"质检报告单"，字段是：

| 字段 | 是什么 | 比方 |
|---|---|---|
| **verdict（判决）** | 最终的 pass / degraded / fail | 盖章结论 |
| **score（分数）** | 0 到 1 的总体评分 | 打分 |
| **level（档位）** | 用的是 basic / standard / strict 哪一档 | 按哪个标准检的 |
| **checks[]（检查明细）** | 每一项的名字、结果、期望值、说明 | 逐项检查表 |
| **issues[]（问题清单）** | 没过关的项，每条都带 `code`、`path`、`fix` | 整改通知单 |
| **metrics（指标）** | 量出来的原始数字 | 原始读数 |
| **facts（事实卡）** | 一行汇总的尺寸体积信息 | 体检小结 |
| **assumptions（假设）** | 哪些值是替你猜的默认值 | 备注"盐适量" |
| **spec_hash（规格指纹）** | 这份规格书的内容指纹 | 菜谱的版本号 |
| **mesh_hash（网格指纹）** | 造出来的几何的内容指纹 | 成品的序列号 |
| **exact（是否精确）** | `false` 表示有些数字是抽样估算的 | 标注"约" |
| **method（方法）** | 用的是哪套测量方法 | 用什么仪器量的 |

**fix（修法）** — 每个失败项都附一条具体怎么改的建议，AI 可以直接照着改。

**code / path（错误码 / 位置）** — 出错的类型和出在规格书的哪一处。

**allow_degraded（允许勉强交付）** — 一个开关。默认关着；打开才能交付 degraded 的模型，等于人签字特批。

**design_default（设计默认值）** — 标记一个值是"我替你定的"，不是量出来的。和实测事实分开记账。

**assumption ledger（假设台账）** — 记录所有"替你猜的默认值"的清单。

## 十、文件与格式

**JSON** — 一种纯文本的数据格式，像填好的表格。人和电脑都能读。

**schema（模式 / 栏目规定）** — 规定这份表格该有哪些栏、每栏填什么类型。

**$param / $expr** — 在规格书里引用变量或写小算式的写法。比如 `{"$expr": "w/2 + 4"}` 意思是"宽度的一半再加 4"。

**GLB / OBJ / STL** — 三种常见三维文件格式，给别的软件或 3D 打印机用。STL 只有形状，OBJ 能带颜色，GLB 是网页和实时显示常用的打包格式。

**BLEND** — Blender 自己的工程文件格式。

**STEP** — 工程师之间传精确图纸的标准格式。里面是 B-rep 而不是三角面，所以下游还能改尺寸、加圆角。

**OpenCASCADE / build123d** — 处理 STEP 这类精确几何的开源工具库。

**manifest（清单）** — 交付时附的一份清单，列出每个文件、校验值和验收记录。

**几何哈希 / 内容指纹** — 一串根据内容算出来的字符，内容一样指纹就一样。用来判断"是不是同一个东西"。

**内容寻址** — 按内容指纹给文件命名。好处是同样的东西永远只存一份。

## 十一、软件与接口

**Python** — 一种编程语言，Atta 是用它写的。

**numpy** — Python 里做数值计算的库，算数字特别快。

**manifold3d** — 专门做"合并 / 挖洞"这类布尔运算的库，又快又稳。

**trimesh** — 处理三角网格的库，功能全但启动慢，所以只当备用。

**Blender** — 免费开源的三维软件，能渲染、能导出各种格式。

**bpy** — Blender 的 Python 遥控接口。Atta 只在最底层用它。

**常驻 worker（常驻工作进程）** — 让 Blender 一直开着等活儿，而不是每次用都重新启动。比方：车间一直开着，来了活直接干，不用每次重新点火。

**CLI（命令行）** — 在终端里敲命令使用，不用点鼠标。

**MCP** — 一种标准协议，让 AI 助手能调用外部工具。比方：统一的插座标准，什么电器都能插。

**DSH 插件 / ZCode 插件** — 把 Atta 装进对应 AI 客户端里的打包方式。

**HTTP 桥** — 在本机开一个小服务，让别的程序通过网址调用 Atta。只监听本机，不对外。

**工具契约（tool contract）** — 规定每个工具叫什么、收什么参数、返回什么。所有地方都照这一份，不许各写各的。

**brep（B-rep 后端）** — 专门处理精确几何的那套代码，能把形状导出成 STEP。

**OCCT / OpenCASCADE** — 一套开源的精确几何引擎，brep 后端靠它工作。

**registry（注册表）** — 一张"有哪些配方、每个配方要什么参数"的总表。给配方登记用的。

**primitives（图元）** — 最基础的形状（方块、圆柱、球等）的生成代码。

**curves（曲线）** — 画二维线条的代码。

**surfaces（曲面）** — 生成曲面的代码。

**boolean（布尔运算）** — 做合并、挖洞、取交集的那部分代码。

**materials（材质）** — 定义陶瓷、金属这类表面质感的代码。

**runtime / worker（运行时 / 工作进程）** — 管着 Blender 进程的那部分代码：启动它、给它派活、收回结果。

**finish（完成面处理）** — 倒角、平滑这类"收尾打磨"的处理。

**bevel（倒角）** — 把尖锐的边磨出一个斜面或圆弧。参数是宽度（毫米）和段数。

**smooth（平滑）** — 让相邻的面看起来连续、没有硬折痕。参数是角度阈值：小于这个夹角就磨平。

## 十二、工作方式

**快环 / 慢环** — 两套节奏。快环是改参数、看形状，0.1 到 1 秒，不渲染；慢环是验收、渲染、导出，慢但必要。比方：先用铅笔速写改构图，满意了再上油画。

**缓存（cache）** — 把算过的东西存起来，下次直接用。比方：切好的菜放冰箱，下次不用重切。

**工作区（workspace / ATTA_HOME）** — Atta 存放模型记录和产物的文件夹。默认是当前目录下的 `_atta/`。

**_atta/** — 工作区里那个文件夹，存模型记录、产物、缓存。删掉缓存只会重建，不丢模型。

**状态（state）** — 记录"这次会话造了哪些模型、每个模型是什么规格"。

## 十三、外观与渲染

**材质（material）** — 表面的质感：陶瓷、金属、塑料。

**PBR（基于物理的渲染）** — 一种让材质看起来真实的方法，按真实的光线反射规律算。

**EEVEE** — Blender 里快的渲染引擎，适合实时预览。

**Workbench** — Blender 里最简单的显示模式，不追求好看，只求看清结构。

**AgX** — 一种调色方式，让很亮和很暗的地方过渡自然，不会一片死白或死黑。

**镜头焦距** — 相机镜头的毫米数。数字大拍得远、变形小，适合产品照。

**正交（orthographic）** — 没有透视变形的投影，像工程图，远处的东西不会变小。

**CIELAB / OKLab** — 描述颜色的数学坐标系，比 RGB 更接近人眼感受。

**Zone System（区域系统）** — 摄影里判断曝光是否合适的分区方法。

**Sobel** — 一种找图像边缘的算法。

**诊断通道** — 不拍好看的照片，而是拍"信息图"：

- **normal（法线）** — 用颜色表示每个面朝哪个方向。
- **depth（深度）** — 越远越黑，看前后关系。
- **id（编号）** — 每个零件一个颜色，看谁是谁。
- **curvature（曲率）** — 用颜色表示弯得厉害不厉害。
- **deviation（偏差）** — 和参考模型比差多少，蓝色是没差，红色是差最多。

## 如果你只想记住三件事

1. **Atta 不靠看图猜形状。** 它把零件写成文字说明（spec），用数学算出形状，然后**量出真实数字**再告诉你。
2. **说"做完了"之前必须过质检。** 验收只有合格、勉强、不合格三种结论，不合格就不许导出文件。
3. **Blender 只是最后的美工。** 形状、测量、验收都不需要它；只有渲染图片和导出某些格式才用到。
