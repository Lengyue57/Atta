## Frozen Cross-Module Contracts

1. **`atta.metrology` (`verify-metrics`)**:
   - `self_intersection(mesh: Mesh, *, max_pairs: int = 200000) -> dict`: returns `{"intersecting_pairs": int, "checked_pairs": int, "self_intersection_ratio": float, "truncated": bool, "exact": bool}` (triangle-triangle Möller/SAT intersection using AABB spatial/BVH broadphase, excluding shared-vertex/edge pairs).
   - `dangling_edge_length_mm(mesh: Mesh) -> float`: total boundary/open edge length in mm (0.0 for closed manifolds).
   - `flux_enclosure_error(mesh: Mesh) -> float`: dimensionless Gauss-divergence surface enclosure residual `|sum(face_area * dot(centroid, normal)) / 3 - volume| / max(volume, eps)` (or `|sum(face_area * normal)| / max(total_area, eps)` vector closure residual; expose `flux_enclosure_error` as dimensionless `[0, inf)` where closed manifold ~`0`).
   - Expose `"self_intersection"`, `"dangling_edge_length_mm"`, `"flux_enclosure_error"` inside `metrology.measure(...)` (optionally toggleable via `self_intersect: bool = True` with fast broadphase so draft stays sub-second).

2. **`atta.probe` & `atta.perception` (`verify-metrics`)**:
   - `probe.compare_meshes_3d(ref_mesh: Mesh, target_mesh: Mesh, *, n_samples: int = 4000, seed: int = 0) -> dict`:
     returns `{"chamfer_mm": float, "chamfer_a_to_b_mm": float, "chamfer_b_to_a_mm": float, "hausdorff_p95_mm": float, "hausdorff_max_mm": float, "volumetric_iou": float, "volume_ref_mm3": float, "volume_target_mm3": float, "n_samples": int, "exact": False}`.
     Use `manifold3d` boolean intersection/union for `volumetric_iou` (with bounded voxel fallback if non-manifold).
   - `perception.diff(a: Mesh, b: Mesh, *, views=None, res: int = 24, compare_3d: bool = True) -> dict`:
     keep existing 2D `views`, `volume_delta_mm3`, `bbox_delta_mm`, `topology_before`, `topology_after`, and add `"metrics_3d": probe.compare_meshes_3d(a, b)` when `compare_3d` is True.

3. **`atta.verify` (`verify-metrics`)**:
   - `verify(mesh, *, constraints=None, level="standard", expected_genus=None, reference_mesh=None)`:
     - Check `self_intersection_ratio` (warn at `standard`, error at `strict`; customizable via `constraints["max_self_intersection_ratio"]`) and `flux_enclosure_error` (`<= 1e-3`).
     - Support `constraints["mesh_agreement"] = {"target_model_id": str, "chamfer_max_mm": float, "hausdorff_p95_max_mm": float, "volumetric_iou_min": float}` evaluated against `reference_mesh` (passed by `engine.verify` after resolving `target_model_id`).
     - Fix stale `"use atta_solve"` string at `verify.py:590` -> `"use atta_variant"`.

4. **`atta.drawing` (`cad-sketch`)**:
   - `project_drawing(mesh: Mesh, *, shape=None, views=("front", "top", "right", "iso"), include_hidden: bool = True) -> dict`:
     returns structured 2D polylines/arcs per view in mm (using OCCT `HLRBRep_Algo` + `HLRBRep_HLRToShape` + `HLRAlgo_Projector` when `shape` B-rep is provided, and pure-numpy crease + silhouette edge extraction fallback for mesh-only models).
   - `export_dxf(path: str, mesh: Mesh, *, shape=None, views=("front", "top", "right", "iso"), title: str = "", units: str = "mm") -> dict`: writes layered DXF (`VISIBLE`, `HIDDEN`, `CENTER`, `ANNOTATION`) via `ezdxf` and returns `{"format": "dxf", "ok": True, "path": ..., "bytes": ..., "backend": "occt_hlr"|"mesh_hlr", "views": [...], "entities": int}`.
   - `export_svg(path: str, mesh: Mesh, *, shape=None, views=("front", "top", "right", "iso"), title: str = "", dims_mm: list | None = None) -> dict`: writes clean 3-view + iso engineering drawing SVG with title block and overall bbox dimensions, returning `{"format": "svg_drawing", "ok": True, "path": ..., "bytes": ..., ...}`.

5. **`atta.curves` & `atta.brep` (`cad-sketch`)**:
   - `curves.eval_sketch_segments(segments, *, samples_per_arc: int = 24) -> tuple[np.ndarray, list[dict]]`:
     compiles declarative 2D `segments` (`line`, `arc`, `tangent_arc`, `circle`, optional `tag`) into a closed `(N, 2)` loop + per-segment metadata.
   - `atta/features.py` & `atta/brep.py`: support optional `segments` on `extrude` / `revolve` (and optional `tags` dict on `extrude` / `revolve` / `box` / `cylinder` / `sphere` / `cone` / `torus`, e.g. `{"end": "cap", "start": "base"}`) plus `common_edge_of: [tagA, tagB]`, `on_face: tag`, `from_feature: id` in `brep.select_edges`.

6. **`atta.spec`, `atta.engine`, `atta.agent.tools` (`spec-patch`)**:
   - `spec.patch_spec(spec: dict, patches: dict) -> dict`: locate-then-infill patching for `recipe`, `graph` (`features: {id: {args, inputs, op, tags}}`, `add_features`, `remove_features`, `params`), and `assembly` (`parts: {id: ...}`), returning `{"ok": bool, "spec": ..., "applied_patches": [...], "delta": {...}, "errors": [...]}`.
   - `spec.preflight_spec(spec: dict) -> dict`: fast non-building preflight validation + dependency/unit/port/selector lint.
   - `engine.spec(..., op="patch"|"preflight", patches=...)` and `engine.model(spec=..., patches=...)` supporting graph/assembly patches.
   - `engine.verify` resolving `constraints.mesh_agreement.target_model_id` -> `reference_mesh`.
   - `engine.deliver(formats=...)` supporting `"dxf"` and `"svg_drawing"` (attempting B-rep HLR via `brep.build_graph` when supported, cleanly falling back to `mesh_hlr` with honest `backend` metadata).
   - `agent/tools.py`: record unknown/dropped tool arguments from `_clean_args` into `"warnings"` on the tool envelope (so LLMs never suffer silent drops!), expose new `op` / `format` options, and tag `[Atta v%s]` consistently.

7. **`atta.conjure`, `atta.design`, `scripts/run_bench.py` (`prompt-bench`)**:
   - `design.stability(mesh)` in `atta/design.py`: pure-numpy center-of-mass XY projection vs `z_min` support convex hull (`stability` rule).
   - `corpus/bench/generalization_v3_prompts.json` (≥ 40 cases across L0/L1/L2/L3 prompt abstraction levels) + `run_bench.py --prompts` scoring `atta_conjure` + `atta_spec(propose)` against executable geometric predicates (zero tautology).

8. **Packaging, Antigravity Install & Docs (`host-docs`)**:
   - Bump version to `1.2.3b1` / `1.2.3-beta.1`.
   - Add `antigravity` install target to `atta/agent/install.py` + `plugins/antigravity/` template files.
   - Sync `docs/ARCHITECTURE.md`, `docs/ROADMAP.md`, `docs/RELEASE-1.2.3beta.md`, `README.md`, `README.zh-CN.md`, `plugin/skills/atta/SKILL.md`, `plugins/atta/skills/atta-modeling/SKILL.md`, `plugin/test/smoke.mjs`, and add `tests/test_docs_sync.py`.
